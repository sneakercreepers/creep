# Package map

Generated by `make map` (internal/tools/pkgmap) from `go list ./...`, the first sentence of each package's `doc.go` and the layers table in [architecture.md §3](architecture.md#3-components-and-layers). Do not edit it by hand: `make check` fails when it is stale. A package may import only lower layers that its row in the table lists; `-` is build tooling, never imported by the product.

| Layer | Package | Purpose |
|---|---|---|
| 0 | [`internal/buildinfo`](../internal/buildinfo/doc.go) | Package buildinfo reports which build of creep is running. |
| 0 | [`internal/exitcode`](../internal/exitcode/doc.go) | Package exitcode defines the process exit codes of creep. |
| 0 | [`internal/presets`](../internal/presets/doc.go) | Package presets turns `model: { preset: <name> }` into a model CLI command line, from reviewed data files embedded in the binary. |
| 1 | [`internal/config`](../internal/config/doc.go) | Package config resolves creep's effective configuration from layers. |
| 1 | [`internal/redact`](../internal/redact/doc.go) | Package redact replaces secrets and personal data with stable markers before any text leaves the machine. |
| 2 | [`internal/gateway`](../internal/gateway/doc.go) | Package gateway is the only code in creep that may touch the network or start a model CLI. |
| 2 | [`internal/gateway/gatewaytest`](../internal/gateway/gatewaytest/doc.go) | Package gatewaytest serves a fake model endpoint on loopback for tests outside the gateway. |
| 3 | [`internal/models`](../internal/models/doc.go) | Package models speaks the model contracts: OpenAI-compatible chat completions (OpenAI, Ollama, vLLM, LM Studio, Groq, OpenRouter), the Anthropic messages API and model CLIs (prompt on stdin, JSON on stdout), with no provider SDK. |
| 3 | [`internal/state`](../internal/state/doc.go) | Package state keeps creep's run state on disk as JSONL, so runs can be recorded, replayed with no network, and resumed after an interruption. |
| 4 | [`internal/calibrate`](../internal/calibrate/doc.go) | Package calibrate measures the user's model per vulnerability class. |
| 4 | [`internal/planner`](../internal/planner/doc.go) | Package planner decides which route→sink hypotheses the reader checks, and in which order, from IDs, enums and booleans only. |
| 4 | [`internal/reader`](../internal/reader/doc.go) | Package reader asks the model whether one hypothesis holds in a slice of redacted code, and turns the answer into a verdict the planner can use. |
| 4 | [`internal/static`](../internal/static/doc.go) | Package static parses repository files into syntax trees so creep can find routes, sinks and auth checks without running the scanned code. |
| 5 | [`internal/report`](../internal/report/doc.go) | Package report turns a run's results into the three report formats: SARIF 2.1.0 (for GitHub code scanning), JSON (schema_version 1, published in docs/schemas/report-v1.json) and Markdown. |
| 5 | [`internal/scanrun`](../internal/scanrun/doc.go) | Package scanrun runs the optional external scanners (gitleaks, osv-scanner) offline, with fixed arguments and no shell, and turns their reports into repository-relative findings. |
| 6 | [`internal/cli`](../internal/cli/doc.go) | Package cli parses the command line and dispatches to subcommands. |
| 7 | [`cmd/creep`](../cmd/creep/doc.go) | Command creep is the entrypoint of the creep CLI. |

| - | [`internal/tools/pkgmap`](../internal/tools/pkgmap/doc.go) | Command pkgmap writes docs/map.md, the package map that agents and contributors read instead of exploring the tree. |
| - | [`internal/tools/testapps`](../internal/tools/testapps/doc.go) | Package testapps guards the deliberately vulnerable apps in testdata/apps. |
