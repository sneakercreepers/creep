# Inventory table (ADR 0017): a label for a file, from its name or bytes.
# Labels are a hint in the prompt and counts in the reports; they never
# decide what is read (#366): every text file is read, and one no rule
# names is labeled "text". The only read a label changes: a file labeled
# as a language whose first 8 KiB hold a NUL is listed read_failed (fail
# closed, #268), never binary. What is not read is formats.txt.
# One rule per line: <match> <pattern> <class> <id>
#   match:   name (exact base name), glob (base name with one "*"),
#            ext (lowercased extension), shebang (interpreter of the "#!"
#            line of an extensionless file or dotfile, through env; tried
#            as written, without version digits, then by leading letters)
#   class:   language, manifest or container
#   id:      a name from the closed lists in inventory.go
# Precedence: name, glob, ext, shebang.
