# Inventory table (ADR 0017): what a file is, from its name or bytes only.
# One rule per line: <match> <pattern> <class> <id>
#   match:   name (exact base name), glob (base name with one "*"),
#            ext (lowercased extension), shebang (interpreter of the "#!"
#            line of an extensionless file, version digits dropped)
#   class:   language, manifest or container
#   id:      a name from the closed lists in inventory.go
# Precedence: name, glob, ext, shebang. A source file with a NUL byte in
# its first 8 KiB is binary and not source. A file no rule names is not
# source; adding an extension is a reviewed data change.
