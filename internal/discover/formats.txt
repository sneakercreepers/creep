# Known non-code formats (#366): the only files discovery does not read as
# text. Every row names a file format, never a language or a package
# manager; discovery needs no row to read a language (ADR 0017 amendment).
# One rule per line: <match> <pattern> <format>
#   match:   name (lowercased base name), glob (lowercased base name with
#            one "*") or ext (lowercased extension)
#   format:  binary formats image, font, media, archive, object, document
#            and store are opened: a file whose first 8 KiB hold a NUL or
#            are not UTF-8 is listed binary; any other is text under a
#            misleading name and is read like any file. Text formats prose,
#            lockfile, data and vector are never opened and listed not_code.
# Precedence: name, glob, ext. Every file no row names is opened: no NUL in
# its first 8 KiB makes it text, read and sent to discovery. The README
# "Not read" list must match (TestDocsListFormats).
